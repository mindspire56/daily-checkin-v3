# 每日打卡 3.0.0 实验站

手机优先的温柔打卡网页，3.0.0 大版本线的独立实验仓库。

- 线上地址：https://mindspire56.github.io/daily-checkin-v3/
- 仓库：mindspire56/daily-checkin-v3
- 当前版本：3.0.0

## 特点

- 自定义模式、自定义打卡任务、自定义鼓励语
- 音乐栏（背景音乐、雨声，引用 daily-checkin-v2 资源）
- 打卡日历与日志
- 分区指引系统
- 一键灵感添加、emoji 语义图标库

## 数据隔离

本仓库使用独立的 localStorage 键 `daily-checkin-v30`，与 `daily-checkin`、`daily-checkin-v2`、`daily-checkin-v21` 老库数据互不干扰。

## 本地工作区

`D:\每日打卡\`：

- `index.html`：当前版本
- `versions/<版本>/index.html`：历史版本快照
- `VERSIONS.md`：版本记录
- `handoff/`：交接文档
